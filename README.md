# Matrix Library (vary type)

Набор модулей для работы с матрицами `int32` и `double` с общим ядром. Проект включает:

- компактную структуру `Matrix`, умеющую оборачивать внешние буферы;
- набор высокоуровневых операций для `double` и `int`: создание, копирование, арифметика, трансформации, операции над строками/столбцами, работа с массивами;
- реализацию LU-разложения с частичным выбором опоры (детерминант и обратная матрица);
- демонстрационные программы и готовую Python-обвязку через `ctypes`.

## Структура

```
matrix_library_vary_type/
│
├── src/
│   ├── matrix_core.{c,h}          — ядро (структура Matrix, обёртки, клоны)
│   ├── matrix_double.{c,h}        — операции над double-матрицами и массивами
│   ├── matrix_int.{c,h}           — эквивалент для int32 + приведение в double
│   ├── matrix_template.h          — общий шаблон, подключается с макросами типа
│   ├── gauss_elim_part_piv.{c,h}  — частичное LU с детерминантом/обратной матрицей
│   ├── cast_int_double_m.c        — вспомогательные функции приведения типов
│   ├── demo.c                     — C-демонстрация возможностей библиотек
│   └── python_example.py          — полный пример использования из Python
│
├── PYTHON_USAGE.md                — руководство по Python-обвязке
└── README.md                      — вы читаете его 🙂
```

## Сборка

```bash
cd matrix_library_vary_type/src

# статические библиотеки (.a)
make static

# динамические библиотеки (.so) — удобны для Python
make shared

# демо-приложение (использует .so)
make demo
# запуск:
LD_LIBRARY_PATH=. ./demo.out
```

## Основные возможности

### Ядро (`matrix_core`)

- `Matrix *mat_new(MatType type, int rows, int cols)` / `mat_free`
- `mat_clone`, `mat_copy`
- `mat_wrap_buffer` — обёртка над внешним буфером (без копирования)
- доступ к данным: `mat_rows_f64/i32`, `mat_data_f64/i32`

### Double-API (`matrix_double`)

- Высокоуровневые операции над матрицами: `create`, `unit`, `copy`, `sum/sub/dot`, `dot_matrix_Hadamard`, `sort`, `transpose`, `swap_rows`, `set_row/col`, `from_array_to_matrix`, `matrix_to_array`, `T_matrix_inplace`.
- Опции ввода-вывода: `scan_matrix_double`, `fill_matrix_double`, `print_matrix_double`.
- Операции над массивами: `scale/add/sub`, их in-place варианты, суммирование/минимум/максимум, поиск индекса по стратегиям (`search_array_index_double`), скалярное и покоординатное произведение.
- Приведение типов: `cast_matrix_to_double`.
- LU-разложение: `matrix_det_lu_double` (режимы `DET` и `INVERSE`).

### Int-API (`matrix_int`)

Аналогичный набор функций для целочисленных матриц. Дополнительно: `cast_matrix_to_double` возвращает `double**`, пригодный для дальнейшей работы с double-библиотекой.

### LU-разложение (`gauss_elim_part_piv`)

`matrix_det_lu_double` возвращает структуру `result_solve`: статус, детерминант, указатель на обратную матрицу и число перестановок строк. Используется как в Си-примерах (`demo.c`), так и в Python.

## Python-обвязка

- `PYTHON_USAGE.md` — справочник по подключению `.so` через `ctypes`, примеры работы с указателями, stdin/stdout Си.
- `src/python_example.py` — живая демонстрация: вызывает **все** публичные функции, перехватывает вывод, показывает работу с `numpy`-совместимыми буферами.

## Рекомендации

- Матрицы, возвращённые функциями `create/clone/sum/sub/...`, освобождайте через `free_matrix_*`.
- Функции, выделяющие массивы (`scale_array_*`, `add_array_*`, `dot_arrays_Hadamard_*` и т.п.), возвращают буфер, который также нужно освободить (`free`).
- Для обёртки существующего буфера используйте `mat_wrap_buffer` и не забудьте освободить только структуру (без данных).
- Python-пример можно использовать как шаблон для тестов или интеграции с NumPy.

## Полезные цели `make`

| Цель         | Что делает                                   |
|--------------|----------------------------------------------|
| `make static`| собирает `libmatrix_core.a`, `libmatrix_double.a`, `libmatrix_int.a` |
| `make shared`| собирает `.so` для использования из Python/других проектов |
| `make demo`  | компилирует `demo.out` и перекомпилирует `.so` |
| `make clean` | удаляет артефакты компиляции                 |

## Лицензия и вклад

Проект учебный; Feel free to дополнять тестами, расширять API или переносить обёртки на другие языки. Если добавляете новые функции, не забудьте:

1. Обновить заголовки (`matrix_*_h`), документацию и пример `python_example.py`.
2. Добавить запись в `PYTHON_USAGE.md`, чтобы оставался живой справочник.
